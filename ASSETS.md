# Arte y derechos

Los 13 SVG de `assets/` se dibujaron específicamente para Frontera Viva 0.6 mediante trazados vectoriales propios: Errante, Vesper, dos soldados, lobo, jabalí, escarabajo, gólem, Ascua, Ojo, dos aldeas y árbol. Están embebidos en `index.html`; `src/art.js` conserva la misma versión para reconstruirlo. No contienen fuentes ni imágenes externas.

El terreno, caminos, grano de papel, contornos, impactos, barras y partículas se dibujan con Canvas 2D. Los sonidos opcionales se sintetizan localmente mediante Web Audio.

No se han incluido assets de terceros. Se consultó el catálogo CC0 de Kenney como alternativa y referencias visuales de juegos móviles, sin redistribuir su arte. Los recursos propios se entregan para usar, editar y redistribuir con este proyecto, sin atribución obligatoria. No se afirma exclusividad registral ni autorización para marcas ajenas.
